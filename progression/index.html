Collection

More wins create an earning base

Winning characters grows the collection, and that collection generates money for continued progression.

02

Luck

Upgrades improve the rarity path

Luck is the verified upgrade route for rolling rarer characters. It improves the route; it is not a promise of a particular result.

03

Variants

Named versions extend collecting

The official experience page names Golden, Diamond, Galaxy, and RAINBOW variants.

04

Rebirth

Titles mark longer progress

Rebirth unlocks unique titles that range from Extra to Final Boss.

Friends

Passes can be gifted

The official experience page says players can give passes to friends.
